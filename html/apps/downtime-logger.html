Downtime Logger

Monitors the DAQ through pluggable detectors (UDP, ZeroMQ, SOAP, logfile, disk) and records downtime events to a database, with a GUI and a web status page.

Start procedure

  1. Bootstrap (first time only)

    Creates ./venv and installs the package editable with its detector dependencies.

    $ cd mu2edaq-downtime-logger
$ ./bootstrap.sh
  2. Start the logger

    Backgrounds the app with config/local.yaml, writing mu2edaq-downtime-logger.pid and .log next to the script. Web status port from apps.yaml (8088). Use --foreground when debugging.

    $ ./start-mu2edaq-downtime-logger.sh
$ ./start-mu2edaq-downtime-logger.sh --config config/local.yaml --log-level DEBUG --foreground
# or: crs-app start downtime-logger
  3. Verify

    The GUI appears; the pytest suite is the fastest full check:

    $ venv/bin/python -m pytest tests -q    # 67 tests
  4. Stop
    $ ./stop-mu2edaq-downtime-logger.sh
# or: crs-app stop downtime-logger

Notes

The package depends on mu2edaq-discovery, which is not on PyPI. Inside the mu2edaq-main checkout install the sibling first: venv/bin/pip install ../mu2edaq-discovery — see mu2edaq-main#4.
Postgres storage is optional: pip install .[postgres].
