File Transfer Service

Moves completed data files off the DAQ hosts (paramiko/scp), with a web control page and optional SAML single sign-on.

Start procedure

  1. Bootstrap the virtual environment (first time only)

    Installs flask, paramiko, scp, python3-saml and friends. On AL9 the SAML stack installs from binary wheels — no system -devel packages needed.

    $ cd mu2edaq-fts
$ ./bootstrap_fts.sh
  2. Start the service

    Daemonizes mu2edaq_fts.py with config/test_config.yaml; the daemon writes config/test_config.pid. Web port from CRS_PORT_HTTP (default 5003), overriding web_server.port in the config.

    $ ./start-mu2edaq-fts.sh
$ ./start-mu2edaq-fts.sh config/my_config.yaml     # alternate config
# or: crs-app start fts
  3. Verify
    $ curl -s http://localhost:5003/ | head
$ venv/bin/python -m pytest tests -q
  4. Stop

    Pass the pid file if you started with a non-default config.

    $ ./stop-mu2edaq-fts.sh
$ ./stop-mu2edaq-fts.sh config/my_config.pid
# or: crs-app stop fts

Notes

If the checkout contains a committed venv/ directory, delete it and re-run the bootstrap — it holds macOS Python 3.12 binaries that cannot work on AL9 (fts#7).
