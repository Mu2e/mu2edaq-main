Disk Watcher

Watches the DAQ data disks and serves a capacity/health status page.

Start procedure

  1. Bootstrap the virtual environment (first time only)
    $ cd mu2edaq-diskwatcher
$ ./bootstrap_diskwatcher.sh
  2. Start the watcher

    Daemonizes diskwatcher.py with config/mu2edaq-diskwatcher.yaml, writing diskwatcher.pid. Web port from CRS_PORT_HTTP (default 5002).

    $ ./start-mu2edaq-diskwatcher.sh
# or: crs-app start diskwatcher
  3. Verify
    $ curl -s http://localhost:5002/ | head
  4. Stop
    $ ./stop-mu2edaq-diskwatcher.sh
# or: crs-app stop diskwatcher
