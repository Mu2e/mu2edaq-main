Questions the review answered

QuestionAnswer
Does diskwatcher's federation actually break the peer cycle, or is it convention?Enforced in code. The peer fetch path has no query string and the API only returns peer data when ?peers= is truthy, so a peer's peers are structurally unreachable. A second guard refuses a URL resolving back to self.
Can one slow peer stall the diskwatcher page?No — handlers only read a snapshot, fetching is a separate thread with a bounded pool and per-peer timeout. Worst case 15 s against a 30 s interval, so under 2× headroom. Runbook item, not a defect.
Is the diskwatcher SSH path injectable from config?The scanned path is safe — shlex.quote per element and the probe takes it as argv[1]. Residual risk needs YAML write access, which already equals start-script privilege.
Have the 28 per-node configs drifted from their template?No drift. All 27 re-rendered and compared byte-for-byte; zero differences. The generator is the source of truth in practice.
Do the C++ and Python dashboard senders emit the same wire schema?Yes, key-for-key and in order. The divergence is in CLI surface: the C++ tool has no --config, so it ignores site YAML entirely.
