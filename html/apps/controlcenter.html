DAQ Control Center

Central control GUI: an embedded web grid of the other DAQ services plus a status bar fed by a TCP status server.

Start procedure

  1. Bootstrap the virtual environment (first time only)

    Creates ./venv and installs PyQt6, PyQt6-WebEngine and PyYAML.

    $ cd mu2edaq-controlcenter
$ ./bootstrap.sh
  2. Start the Control Center

    Runs src/controlcenter.py in the background with config/controlcenter.yaml and writes controlcenter.pid. The status-server port comes from CRS_PORT_CMD (exported by crs-app; default 9876).

    $ ./start.sh
# or via the control-room launcher:
$ crs-app start controlcenter
  3. Verify

    The GUI window opens on the current display. Push a test message to the status bar:

    $ venv/bin/python src/controlcenter_send.py --port 9876 "status: test message"
  4. Stop
    $ ./stop.sh
# or: crs-app stop controlcenter

Notes

Needs a display (VNC session shift-main in production). For headless smoke tests set QT_QPA_PLATFORM=offscreen.
