CFO Control

Command-line control of the CFO via the MacroMaker UDP interface — runs in a terminal, no virtual environment needed.

Start procedure

  1. Run

    Pure-stdlib Python 3; point it at the MacroMaker host (UDP port 5000 per apps.yaml).

    $ cd mu2edaq-CFOControl
$ python3 CFOControl.py --host <macromaker-host> --port 5000
$ python3 CFOControl.py --config my_cfo.yaml
  2. Stop
    # interactive - exit the CLI (Ctrl-D / quit)
