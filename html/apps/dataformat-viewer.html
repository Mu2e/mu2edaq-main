Data Format Viewer

Displays Mu2e ROC packet bytes decoded field-by-field from YAML format definitions; data comes in by hand, from file, or over TCP from the companion sender.

Start procedure

  1. Install dependencies (first time only)

    PyQt6 and PyYAML, plus the discovery sibling inside mu2edaq-main.

    $ cd mu2edaq-dataformat-viewer
$ python3 -m venv venv
$ venv/bin/pip install ../mu2edaq-discovery -r requirements.txt
  2. Start the viewer

    Backgrounds the viewer with dataformat-viewer.pid/.log next to the script. TCP listen port 7755 from CRS_PORT_LISTEN. Format definitions live in formats/.

    $ ./start-mu2edaq-dataformat-viewer.sh
# by hand:
$ venv/bin/python mu2edaq-dataformat-viewer.py
# or: crs-app start dataformat-viewer
  3. Start the sender (second terminal)

    Builds packets field-by-field from the same YAML definitions and ships them to the viewer.

    $ venv/bin/python mu2edaq-dataformat-sender.py
  4. Optional: build the C++ helper
    $ cmake -S cpp -B build-cpp && cmake --build build-cpp -j
  5. Stop
    $ ./stop-mu2edaq-dataformat-viewer.sh
# or: crs-app stop dataformat-viewer
