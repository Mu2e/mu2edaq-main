Control Room Utilities

Grab-bag of control-room support tools: Kerberos ticket lifecycle, VNC tunnels, GitHub organisation helpers, and DAQ environment capture/restore.

Start procedure

  1. Install dependencies (for the Kerberos tools)

    The krb5 Python package compiles against krb5-devel (present on the DAQ hosts).

    $ cd mu2edaq-controlroom
$ python3 -m venv venv && venv/bin/pip install -r requirements.txt
  2. Kerberos tickets
    $ venv/bin/python kerb.py                 # show active principal + caches
$ venv/bin/python ticket-manage.py        # Qt6 GUI ticket manager
$ bin/GetTicket.sh                        # TGT from keytab (macOS/Linux aware)
# headless renewal from cron:
$ venv/bin/python mu2e-krb-cron.py
  3. VNC tunnels (requires a valid ticket)
    $ bin/start_vnc_tunnels_mu2e.sh open
$ bin/start_vnc_tunnels_mu2e.sh close
  4. Environment capture / restore
    $ ./daq_env_tools.py -c -o snapshot.json   # capture
$ ./daq_env_tools.py -r -i snapshot.json   # restore

Notes

The Mu2eCR/ tree is NOvA-era legacy under review (controlroom#3).
