Resource Manager

Central allocator for shared DAQ resources; FastAPI server with a web view, a Python CLI, and a C++ client library.

Start procedure

  1. Install server dependencies (first time only)

    fastapi / uvicorn / pyyaml / requests into a venv. Inside mu2edaq-main also install the discovery sibling.

    $ cd mu2edaq-resource-manager
$ python3 -m venv venv
$ venv/bin/pip install ../mu2edaq-discovery -r requirements.txt
  2. Start the server

    Daemon mode; port precedence CRS_PORT_HTTP > RM_PORT > 8080. Extra args go to scripts/start_server.sh.

    $ ./start-mu2edaq-resource-manager.sh
# or: crs-app start resource-manager
  3. Verify
    $ curl -s http://localhost:8080/ | head
  4. Optional: build the C++ client library
    $ cmake -S . -B build && cmake --build build -j
  5. Stop
    $ ./stop-mu2edaq-resource-manager.sh
# or: crs-app stop resource-manager

Notes

Configuration lives in config/; copy example.env to .env to override defaults.
