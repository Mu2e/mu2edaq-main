DAQ Message Dashboard

Receives DAQ messages over ZeroMQ PUSH/PULL, logs them to SQLite, and serves a live browser dashboard over WebSocket.

Start procedure

  1. Bootstrap the virtual environment (first time only)

    Creates ./venv, installs pyzmq / flask / flask-socketio / pyyaml, and creates the data, logs and config directories.

    $ cd mu2edaq-dashboard
$ ./bootstrap_dashboard.sh
  2. Start the dashboard

    Daemonizes dashboard.py with config/dashboard_config.yaml and writes dashboard.pid. Web port from CRS_PORT_HTTP (default 5001), ZMQ ingest port from CRS_PORT_ZMQ (default 5555).

    $ ./start-mu2edaq-dashboard.sh
# or: crs-app start dashboard
  3. Verify

    Open the web UI and send a test message with the bundled Python sender:

    $ curl -s http://localhost:5001/ | head
$ venv/bin/python sender.py --port 5555 --count 3
  4. Optional: build the C++ sender

    For C++ producers; requires cmake ≥ 3.15 and libzmq (zeromq-devel on AL9).

    $ cmake -S . -B build && cmake --build build -j
$ ./build/mu2edaq_sender --help
  5. Stop
    $ ./stop-mu2edaq-dashboard.sh
# or: crs-app stop dashboard
