Operations Scripts

Day-to-day cluster operations: node inventory, temperature readout, IPMI, server health checks, and PCIe card setup.

Start procedure

  1. Install Python dependencies (first time only)
    $ cd mu2edaq-operations
$ python3 -m venv venv && venv/bin/pip install -r requirements.txt
  2. Node inventory
    $ venv/bin/python node_list.py --help     # list nodes from YAML inventory
$ venv/bin/python node_edit.py            # interactive inventory editor
$ venv/bin/python mu2e_node_lookup.py <node>
  3. Health and hardware
    $ ./read_node_temps.sh        # CPU temperatures across nodes
$ ./read_dtc_temps.sh         # DTC card temperatures
$ ./mu2e_ipmi.sh <node> ...   # IPMI wrapper
$ ./server_checks.sh          # health sweep (pssh variant available)
  4. PCIe / driver setup on AL9
    $ ./setup_pcie_AL9.sh
$ ./check_update_pcie_version.sh
