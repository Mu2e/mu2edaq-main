Shifter Tools

Utilities shifters use to bring up ots environments, verify the network, and move files around the cluster.

Start procedure

  1. Run directly (no build step)
    $ cd mu2edaq-shifter-tools
$ ./daq-network-verify.sh            # check DAQ network reachability
$ ./get_krb_principal.sh             # show current Kerberos principal
$ python3 open_tunnels.py            # open standard shift tunnels
$ python3 cluster_cp.py SRC DST      # copy across cluster nodes
$ python3 install_daq_tools.py       # install these tools for the account

Notes

setup_online / start_daq for ots partitions are described in the README; their environment config (partitions → test releases) is per-installation.
