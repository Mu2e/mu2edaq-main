Control Room Setup (crs-*)

Provision and operate the control-room VNC sessions and SSH tunnels from your own machine, through the FNAL gateway. Also owns apps.yaml — the single source of port truth.

Start procedure

  1. Install on your client machine (first time only)
    $ cd mu2edaq-controlroom-setup
$ ./bootstrap.sh          # venv + editable install with GUI extras
  2. First-time host setup

    Ships scripts/configs to every (host, account) pair and generates desktop icons.

    $ venv/bin/crs-remote install --all
$ venv/bin/crs-remote provision --all
  3. Daily operation

    Start everything, connect a session viewer, or drive it from the GUI:

    $ bin/start-controlroom.sh                       # all sessions + all tunnels
$ venv/bin/crs-tunnel connect --session daq-main # one VNC viewer
$ venv/bin/crs-gui                               # PyQt6 control panel
$ bin/stop-controlroom.sh                        # tear it all down
  4. Piecemeal control
    $ venv/bin/crs-remote {start|stop|status} --session NAME|--host H|--all
$ venv/bin/crs-tunnel {open|close|status|connect} --session NAME|--all

Notes

Sessions (from config/controlroom.yaml): shift-main, shift-aux, daq-main, daq-aux, daq-dl2 … Desktop icons run crs-app start <id>, which exports CRS_PORT_<NAME> from apps.yaml and execs the app's standardized start script.
