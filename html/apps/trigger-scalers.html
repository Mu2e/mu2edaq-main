Trigger Scalers

Live trigger-rate scaler display; receives counts over UDP or ZeroMQ and renders a Qt board sized for the control-room wall.

Start procedure

  1. Build (first time only)

    Requires cmake ≥ 3.16, a C++17 compiler, Qt5 or Qt6 dev packages, yaml-cpp; ZeroMQ support is on by default.

    $ cd mu2edaq-trigger-scalers
$ cmake -B build -DWITH_ZEROMQ=ON      # add -DUSE_QT6=ON for Qt6
$ cmake --build build -j
  2. Start the display

    The standardized script builds the binary with CMake if missing, then backgrounds it in the VNC session. UDP listen 5557 (moved off 5555, which the dashboard's ZMQ owns) and ZMQ 5556, from CRS_PORT_UDP / CRS_PORT_ZMQ.

    $ ./start-mu2edaq-trigger-scalers.sh
# by hand, with overrides:
$ ./build/trigger-scalers --config config/scalars.yaml --protocol zeromq --size large
# or: crs-app start trigger-scalers
  3. Verify

    Send test counts with the bundled tool (built when WITH_ZEROMQ=ON):

    $ ./build/zmq-sender --port 5556
  4. Stop
    $ ./stop-mu2edaq-trigger-scalers.sh
# or: crs-app stop trigger-scalers
