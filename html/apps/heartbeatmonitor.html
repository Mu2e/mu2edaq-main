Heartbeat Monitor

Listens for JSON heartbeat packets over UDP from DAQ applications and shows a live green/red status board in the browser.

Start procedure

  1. Bootstrap the virtual environment (first time only)
    $ cd mu2edaq-heartbeatmonitor
$ ./bootstrap_heartbeat_monitor.sh
  2. Start the monitor

    Ports come from apps.yaml via crs-app: HTTP 8081 (moved off 8080, which resource-manager owns) and UDP 9999.

    $ venv/bin/python heartbeat_monitor.py --config config/heartbeat_monitor.yaml
# or: crs-app start heartbeatmonitor
  3. Verify

    Send a heartbeat with the bundled sender, then check the web page:

    $ venv/bin/python heartbeat_sender.py -n test-app -s OK --host 127.0.0.1 -p 9999
$ curl -s http://localhost:8081/ | head
  4. Optional: build the C++ sender

    Same CLI as the Python sender; fetches nlohmann/json at configure time if not installed.

    $ cmake -S cpp_sender -B build-sender && cmake --build build-sender -j
$ ctest --test-dir build-sender
  5. Stop
    $ crs-app stop heartbeatmonitor   # or kill the pid from --pid-file
