Run Log Database

Web viewer for the Mu2e run-log Postgres database. Django only creates its own auth/session tables — the run-log tables are never modified.

Start procedure

  1. Bootstrap (first time only)

    Creates the venv and installs Django 4.2, allauth, psycopg2 and gunicorn; set database credentials in .env.

    $ cd mu2edaq-runlog-db
$ ./bootstrap-mu2e-rundb-viewer
$ cp config/env.example .env && $EDITOR .env   # DB credentials
  2. Start the viewer

    Runs manage.py migrate then gunicorn (4 workers). Environment: DJANGO_ENV (development|production), RUNLOGDB_HOST (default 127.0.0.1), port precedence CRS_PORT_HTTP > RUNLOGDB_PORT > 8000.

    $ ./start-mu2edaq-runlog-db.sh
# or: crs-app start runlog-db
  3. Verify
    $ curl -s http://localhost:8000/ | head
$ venv/bin/python manage.py check
  4. Stop
    $ ./stop-mu2edaq-runlog-db.sh
# or: crs-app stop runlog-db

Notes

A Dockerfile is provided as an alternative deployment; the container entrypoint keeps gunicorn in the foreground.
