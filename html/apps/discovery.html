Service Discovery

UDP multicast service discovery: see which DAQ applications are running, where, and who they are. Applications embed a tiny responder; operators query with one command.

Start procedure

  1. Install
    $ cd mu2edaq-discovery
$ ./bootstrap.sh        # venv + dev deps
# or into an existing environment:
$ pip install -e .
  2. Query the network
    $ mu2edaq-discover                          # table of everything
$ mu2edaq-discover --filter app=vnc         # only VNC sessions
$ mu2edaq-discover --json | python3 -m json.tool
  3. Embed a responder in your application

    Two lines; protocol mu2edaq-discovery/1 on multicast 239.255.42.99:28999 (see doc/PROTOCOL.md).

    from mu2edaq_discovery import Responder
Responder(app="myapp", port=5001).start()

Notes

Multicast does not traverse the FNAL gateway — query from inside the DAQ network. Config precedence: CLI > MU2EDAQ_DISCOVERY_* env > --config YAML > defaults.
