Big Red Box Alerts

Listens for UDP broadcast alerts and throws a full-screen red alert window at the shifter when one arrives.

Start procedure

  1. Install dependencies (first time only)

    PyQt5 ≥ 5.15 into a venv (or the session's shared environment).

    $ cd mu2edaq-bigredbox
$ python3 -m venv venv && venv/bin/pip install -r requirements.txt
  2. Start the alert listener

    Backgrounds daq_alert.py; UDP port from CRS_PORT_UDP (default 37020). Writes /tmp/daq_alert.pid and logs to /tmp/daq_alert.log. DISPLAY must point at the shifter screen.

    $ ./start_daq_alert.sh
# or: crs-app start bigredbox
  3. Verify

    Fire a demo alert from any machine on the subnet:

    $ venv/bin/python demo_sender.py
  4. Stop
    $ ./stop_daq_alert.sh
# or: crs-app stop bigredbox

Notes

This is the only PyQt5 app in the suite (everything else is PyQt6/PySide6) — see mu2edaq-main#2.
